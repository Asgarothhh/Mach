Как звучит каждая эмоция

Одна и та же фраза синтезирована для всех 14 эмоций атласа (docs/SPEC_MASCOT_FACE.md §6/§9.3): один сэмпл — листайте эмоции и смотрите, как куб говорит вместе с голосом (рот синхронизирован с амплитудой звука). Chatterbox передаёт эмоцию нативно через exaggeration; Silero MIT нативной эмоции не имеет — это честная деградация, где применена только таблица просодии (темп, высота, громкость). Выберите движок:

Клик по эмоции — куб меняет мимику, а озвучка переключается на её сэмпл.

Честные пометки

  • Chatterbox V3 (MIT, код и веса): эмоциональность — нативный параметр exaggeration адаптера speech/tts/chatterbox_tts.py; каждый выход содержит PerTh-водяной знак Resemble AI.
  • Голос Chatterbox улучшен по результатам лабораторного прогона (UTMOSv2 MOS 2.71 → 3.59): предустановка ударений (RuAccentStressPreprocessor, ruaccent MIT — заменяет недоступный russian_text_stresser), референс тембра (синтез Silero MIT ru_ekaterina) и cfg_weight 0.30. Модель перезагружается каждые 4 сэмпла: у Chatterbox есть известная деградация качества на длинных сериях (resemble-ai/chatterbox #360).
  • Silero v5_cis_base_nostress (MIT, голос ru_alexandr): нативного управления эмоцией нет; применена только просодия из спеки — так выглядит «честная деградация», когда движок не умеет эмоцию (SSOT NFR-10).
  • Просодия из таблицы §9.3 (темп/высота/энергия) применена ffmpeg-фильтром rubberband с сохранением формант: phase vocoder давал слышимые артефакты (UTMOS 1.1 против 2.5 после фикса). Перед внедрением в агент таблицу нужно проверить бенчмарком разборчивости (scripts/tts_ab_eval.py, WER round-trip) и зафиксировать ADR + правку SSOT §5.7.
  • Злость в агенте — policy-off: по умолчанию не направляется клиенту, здесь показана только как часть атласа.
  • Эта страница и аудио собраны scripts/emotion_demo_build.py; значения exaggeration и просодии — из спеки, не из рантайма агента.
