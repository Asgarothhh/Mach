Сэмплы TTS — Silero v5.5 RU, 48 кГц

0 — приветствие
1 — вопрос с интонацией *Вы*
2 — цена, числа
3 — вопрос-предложение

Синтез локальный (CPU-only). Сегмент 1 — проверка фичи из публикации: постановка вопросов и интонационный центр *слово* (habr.com/ru/articles/1015942).

Железо: CPU-only, torch 2.14.1+cpu, 12 потоков (RTX 3060 в стенде пока не задействован). Целевой ориентир SSOT §5.8 — 50–150 мс на прогретой модели; цифры честно показываются как есть. Транспортные чанки ≤ 120 мс — для быстрой отмены при barge-in.

Что уже в ветке audio

  • Контракты: AudioFrame, VADEvent, ASREvent, TTSRequest/TTSChunk, CancellationToken, типизированные ошибки — ровно по SSOT §5.4/§5.7.
  • Streaming VAD: Silero VAD (MIT) + собственный endpointing-автомат (min_speech, min_silence, prefix_padding, max_utterance, гистерезис) — пороги конфигурируемы, стартовые значения SSOT §5.3.
  • Streaming TTS: Silero v5.5 RU с интонацией вопросов, ударениями и омографами; чанки с generation_id (отмена устаревших), first_chunk_ms для latency-бюджета.
  • Защита транскрипта: поздний partial не перезаписывает final, дубликаты не создают ходы.
  • Mock ASR: детерминированный interim→final для E2E этапов 0–1.
  • Тесты: 36 unit (без весов) + 1 integration на реальной модели; ruff зелёный.

Лицензии — важное

Голос v5_5_ru — CC BY-NC-SA 4.0 (некоммерческая): демо и внутренняя оценка. Для production — отдельная лицензия Silero либо MIT-модель v5_cis_base_nostress (voice-модели лицензируются отдельно). Полный разбор — LICENSES.md, версии и SHA-256 — config/models.lock.yaml.

Дальше по плану ML

  • Streaming ASR: sherpa-onnx (T-One CTC RU / Zipformer RU) + baseline faster-whisper large-v3-turbo; WER/latency на своём наборе.
  • Набор речевых тестов (≥200 фраз, синтетика/обезличенное) и метрики по числам, суммам, датам.
  • Калибровка порогов VAD на шум/паузы/перебивания; замер ложных срабатываний.
  • E2E barge-in (VAD → cancel → flush TTS) вместе с Backend + ML-Flow.
