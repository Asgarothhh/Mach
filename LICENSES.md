# Dependency and model license review

This frontend starter does not bundle model weights or voice assets. Before shipping, verify the licenses and supported versions of dependencies in `package.json` and record the approved versions/license references here or in the team's license inventory.

Backend model/voice assets, including ASR, embeddings, reranker, and TTS voice models, require separate license review as specified in `SPEC_MTS_VOICE_AGENT.md`.
